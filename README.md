#  Member Management System (Desktop Application)

A full-stack member management application designed to manage member data efficiently with a clean UI and secure backend.  
The application runs as a desktop app and communicates with a hosted API.

---

##  Features

### Member Management

- ➕ Add new members  
- 📋 View all members  
- 🔍 Search members by name  
- 📄 View detailed member information  
- 🏷️ Filter members by:
  - Permanent
  - Temporary  

---

###  Member Details

- Name, Phone Number  
- Blood Group  
- Address (Permanent & Temporary)  
- Email  
- Profession & Workplace  
- Membership Type  
- Registration Details  
- Fees & Donations  

---

###  UI Features

-  Desktop application (Electron-based)  
-  Clean and responsive UI (Tailwind CSS)  
-  Modal-based form (overlay)  
-  Background dim effect for focus  
-  Fast and interactive experience  

---

###  Authentication

- Token-based authentication (Laravel Sanctum)  
- Secure API communication using Bearer Token  

---

##  Tech Stack

###  Frontend

- React.js  
- Tailwind CSS  
- Axios  

###  Desktop

- Electron.js  

###  Backend

- Laravel (PHP)  
- REST API architecture  

###  Database

- PostgreSQL
